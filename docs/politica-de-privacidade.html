Política de Privacidade — Avisador CF2A

Última atualização: 8 de outubro de 2026 · Versão dos termos v1.0

1. Quais dados são coletados

O aplicativo não coleta dados. Nada é enviado a servidores do desenvolvedor ou de terceiros. Os dados que você digita ou cola no programa (tabela de agendamentos, nomes, cadastros, telefones, horários, histórico gerado e configurações) permanecem apenas no seu computador.

Não há analytics, rastreamento, publicidade ou cookies.

2. Como são armazenados

Os dados ficam gravados somente no perfil local do aplicativo, dentro da pasta do seu usuário no Windows (%LOCALAPPDATA%). Nenhum armazenamento em nuvem é utilizado.

3. Como são utilizados

Os dados são usados unicamente no dispositivo para gerar as mensagens de aviso, exibir o histórico do dia/sessão e copiar textos para a área de transferência quando você clica nos botões do programa.

4. Direitos do usuário (LGPD/GDPR)

Você é o titular dos dados inseridos. Pode acessá-los, corrigi-los ou excluílos a qualquer momento pelos botões “Limpar”, “Histórico limpar” e “🧹 Dados locais” do próprio programa, ou desinstalando o aplicativo (o Windows remove os dados locais junto com ele).
